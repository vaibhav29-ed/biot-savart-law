# Biot–Savart Law Simulation

A Python project that numerically computes and visualizes magnetic fields around current-carrying conductors using the vector form of the Biot–Savart law.

## Overview

The repository provides a 3‑D numerical simulation of magnetic fields generated by steady currents. It implements the Biot–Savart law to calculate field vectors on a configurable grid and visualizes the results with Plotly.

## Features

- Vector field calculation using the Biot–Savart integral.
- Interactive 3‑D rendering of magnetic field vectors with Plotly cones.
- Evaluation on a customizable 3‑D grid.
- Support for multiple wire geometries (straight, circular, optional random‑shaped loop).


- `biot-savart-sim.py` and `final code.py` contain the primary simulation and visualization logic.
- `.ipynb_checkpoints/` stores Jupyter notebook checkpoints used during development.
- `Readme.md` documents the project.

## Technology Stack

- **Language**: Python
- **Numerical libraries**: NumPy (core vector operations), SciPy (optional integration), SymPy (symbolic work in notebook), Matplotlib (optional plotting).
- **Visualization**: Plotly (interactive 3‑D cones and scatter plots).
- **Development environment**: Standard Python interpreter; no container or CI configuration is present.

## Prerequisites

A Python environment with the following packages installed:

- `numpy`
- `plotly`

(Other optional imports such as `scipy`, `sympy`, and `matplotlib` appear in the notebook checkpoint but are not required for the main scripts.)

## Installation

The repository does not provide a documented installation procedure. Users should ensure the prerequisite Python packages are available in their environment before running the scripts.

## Usage

Run one of the main simulation scripts from the command line:

```bash
python biot-savart-sim.py
```

or

```bash
python "final code.py"
```

The scripts will open an interactive Plotly window displaying the current loop and the surrounding magnetic field vectors.
